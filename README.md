# ferramentas-sistema

Utilitários e scripts para diagnóstico, limpeza, manutenção e resolução de problemas em ambientes Windows.

## Ferramentas e arquivos incluídos

- **`CleanerCLI.exe`**: Utilitário de linha de comando para limpeza e análise de disco no Windows.
- **`Remover-Apple-Mobile-Device.bat`**: Script Batch para remoção/limpeza de componentes ou serviços relacionados ao Apple Mobile Device no Windows.
- **`Solucao-Problemas-Programas.bat`**: Script Batch voltado à correção e diagnóstico de falhas comuns em programas no Windows.
- **`INFORMAÇÕES.md`**: Documentação complementar com detalhes sobre as ferramentas (como o utilitário de limpeza de disco).

## Pré-requisitos

- Sistema operacional **Windows** (Windows 10 / Windows 11).
- **Privilégios de Administrador** ao executar scripts `.bat` ou utilitários que alteram serviços, arquivos temporários ou configurações do sistema.
